# 02-bd — Thiết Kế Cơ Bản (Basic Design)

> **VAI TRÒ TRONG KIẾN TRÚC LINGORA:**
> Phase 02 chịu trách nhiệm thiết kế tổng thể kiến trúc hệ thống, sơ đồ phân cấp màn hình (Screen Hierarchy), và kiến trúc dữ liệu mức khái niệm trước khi chuyển sang thiết kế chi tiết.

## Cấu trúc:
- `screens/`: Sơ đồ các màn hình và luồng điều hướng (Landing $\rightarrow$ Roadmap $\rightarrow$ Dashboard $\rightarrow$ Lab $\rightarrow$ Lesson Runner).
- `architecture/`: Cấu trúc lộ trình 4 mốc (Milestones A1 $\rightarrow$ B2 IELTS 6.5) và máy trạng thái học viên.
- `data/`: Sơ đồ thực thể dữ liệu khái niệm (Conceptual ERD: Learner, Lesson, Exercise, Attempt, Proof).
