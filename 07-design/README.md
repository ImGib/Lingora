# 07-design — Bản Mẫu Tương Tác & Hệ Thống Design Tokens (UI/UX & Prototype)

> **VAI TRÒ TRONG KIẾN TRÚC LINGORA:**
> Phase 07 lưu trữ toàn bộ bản mẫu giao diện tương tác (Prototype độc lập), tài nguyên đồ họa SVG khẩu hình miệng, và file định nghĩa Design Tokens chuẩn Soft Study Palette.

## Cấu trúc:
- `README.md`: Hướng dẫn này.
- `design-tokens.json`: Bảng màu Soft Study (`indigo`, `mint`, `peach`, `blush`), Typography, Component standards.
- `index.html`, `app.js`, `styles.css`: Bản mẫu giao diện tương tác độc lập (bấm thử trên trình duyệt).
- `stakeholder-hub.html`: Cổng thông tin tương tác cho khách hàng, BA, QA và giáo vụ.
- `assets/`: Biểu tượng, mascot và SVG khẩu hình miệng.
