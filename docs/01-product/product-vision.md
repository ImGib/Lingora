# Product Vision

**Status:** BASELINE

Lingora is a self-contained English learning system for an adult learner progressing from uncertain foundations through academic English, IELTS Academic performance, and practical study-abroad readiness. It is not an IELTS question bank and not an AI chat wrapper.

## Promise

The learner should always understand:

- what to do next;
- why that action was selected;
- what evidence supports the diagnosis;
- what help was used and how it changes interpretation;
- how today's work connects to the longer goal;
- what recovery path exists after difficulty, interruption, or technical failure.

## Product principles

1. Learning quality outranks completion metrics.
2. A learner profile is multidimensional; there is no single global “English level.”
3. The system teaches language before optimizing exam technique.
4. The daily plan adapts to time, fatigue, evidence, learning debt, and the goal while protecting curriculum continuity.
5. Feedback must lead to self-correction, targeted practice, rewrite/retry, transfer, and later verification.
6. Sustainability is a system constraint: breaks, lighter days, consolidation, and safe return after absence are first-class.
7. Uncertainty is shown and managed rather than hidden behind precise-looking scores.

## Success

Success is a defensible learner profile: durable language knowledge, skill performance across modalities and contexts, exam readiness supported by calibrated benchmarks, and the ability to function in study-abroad situations. It is not simply course completion or one mock-test score.
