# System Maturity

| Horizon | NOW | PROTECT | LATER |
|---|---|---|---|
| M0 | deterministic kernel, lineage, identity, safe planning | async boundary, reprojection, governance | distributed services, generic event platform |
| M1 | 28-day content, reviews, probes, recovery v1, artifacts v0, planner v1 | calibrated evidence, richer multimodal evaluation | universal SRS, full ASR/AI scoring |
| Beyond | measured curriculum expansion | academic/IELTS separation | optimization and service extraction only from evidence |

Maturity is multidimensional: technical completion cannot compensate for missing content, pedagogy, data validity, security, accessibility or real-learner proof.
