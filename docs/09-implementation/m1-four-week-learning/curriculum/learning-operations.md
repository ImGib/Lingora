# M1 Learning Operations

## Session shapes

- **10–15 minutes:** highest-priority due review, one core continuation, close/next step.
- **About 60 minutes:** entry → retrieval → learn/input → guided practice → independent use → feedback → close.
- **More than 60 minutes:** split into sessions with breaks; do not stretch one uninterrupted activity block.

## Recovery contract

Repeated meaningful difficulty creates a suspected issue, not a diagnosis. Run a short verification probe; if the pattern persists, choose a targeted explanation or micro-practice, then offer a new independent item/context. Record intervention and subsequent performance so `effective`, `ineffective` and `unknown` remain distinguishable. If evidence cannot identify a cause, `UNKNOWN CAUSE` is valid.

## Planner v1 contract

Inputs: active episode, unfinished work, due reviews, claim uncertainty/missing coverage, suspected issues, available time, learner preference and usable modality/device conditions.

Candidate types: `RESUME`, `REVIEW`, `LEARN`, `PRACTICE`, `VERIFY`, `RECOVER`, `TRANSFER`, `INTEGRATED_CHALLENGE`, `BREAK`, `FINISH_DAY`.

The planner selects a small DailyPlan; NextAction projects its preferred executable block and reason. Learner `SKIP`, `DEFER`, `REPLACE` and `EXPLORE` are distinct. A minimum viable day remains valid; missed days trigger replanning, never fabricated failure or an impossible backlog.
