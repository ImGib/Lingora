# Week 4 — Needs, Preferences & Integration

**Communicative goal:** handle simple everyday communication using learned language.

Language and skills: like/don't like, want/need, can, I'd like, basic questions, `and / but / because`, sentence stress and basic connected speech. Week 4 emphasizes integration rather than a large new grammar load.

| Day | Episode intent | Core experience | Evidence posture |
|---:|---|---|---|
| 22 | Preferences | like/don't like with familiar topics | exposure + practice |
| 23 | Needs and requests | want/need/can/I'd like; basic questions | guided practice |
| 24 | Understand exchanges | short requests/preferences in audio/text | first-pass comprehension |
| 25 | Connect ideas | and/but/because; sentence stress | controlled independent use |
| 26 | Rehearse integration | partial challenge with optional scaffolding | practice, not final evidence |
| 27 | Integrated challenge | unseen profile/audio → comprehension → original writing/speaking/follow-up | independent multi-skill evidence |
| 28 | Delayed check and reflection | selected novel probes, reflection and next recommendation | retention/transfer; uncertainty retained |

## Integrated challenge — Meet a new classmate

The learner reads a short profile, listens to an introduction, answers meaning/detail questions, writes a short original message/introduction, then records an introduction and answers follow-ups. Technical or microphone failure invokes text, self-check, queued processing or another valid modality; it produces no negative learner evidence.
