# M1 Definition of Done

M1 is done only when a representative beginner can use Lingora for 28 continuous days, including missed-day recovery, and complete all four learning episodes plus the integrated challenge without a required path being mocked.

Required proof:

- all six capability outcomes have an explicit coverage report; unsupported claims remain unknown;
- independent production, near transfer and delayed verification are distinguishable from supported practice;
- review and recovery work without turning one error into a diagnosis;
- Starting Point Check can be completed or skipped safely;
- planner supports 15-minute minimum days, longer sessions, pause/resume and learner overrides;
- content/version/evaluator/policy lineage and DecisionTrace reproduce consequential results;
- unhealthy content can be quarantined and affected inference reviewed;
- privacy, learner isolation, idempotency, accessibility and degraded modes pass release gates;
- real-learner evidence supports “meaningful for 28 days”; completion/streak alone is insufficient.

Writing/speaking v0 may use capture, playback and structured self/deterministic checks. Automated AI/ASR scoring is not required and cannot be presented as validated proficiency measurement.
