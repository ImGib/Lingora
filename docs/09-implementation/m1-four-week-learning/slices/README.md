# M1 Vertical Slices

Create a slice brief here only when it is ready for implementation. Each brief must deliver a learner-visible thread through content, UI, API, domain, persistence, evidence and next action; state `NOW / PROTECT / LATER`; and name its content, pedagogy, measurement, security/privacy, accessibility, degraded-mode and real-learner gates.

The first implementation-ready brief is [01 — Entry and Week 1](01-entry-and-week-1.md). Later slice files are intentionally absent until evidence from this slice and the coverage matrix makes their boundaries concrete.
