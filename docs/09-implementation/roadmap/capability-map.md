# Capability Map

The canonical path is:

```text
Language Model -> Competency -> Learning Claim -> Opportunity -> Evidence -> State -> Decision
```

M1 capability groups are personal information, daily routines, familiar people, needs/preferences, simple input comprehension and short independent production. Vocabulary, grammar, sounds/pronunciation, listening, reading, writing and speaking support those communicative capabilities; they are not isolated course silos.

Later expansion adds broader contexts, interaction/repair, sustained discourse, academic reading/listening/note-taking, paraphrase/synthesis, IELTS strategy and timed performance. `Language Capability != IELTS Strategy != IELTS Performance` remains protected.
