# Learner Journey Roadmap

```text
Starting Point Check (optional)
  -> M1: 28-day beginner foundation
  -> broader English foundation
  -> academic English
  -> pre-IELTS
  -> IELTS skills and timed performance
  -> study-abroad communication
```

The journey is capability-led, not lesson-count-led. `Unknown != Weak`; skipping the Starting Point Check starts at the beginning and lets evidence accumulate gradually. Each stage uses learning episodes, review, recovery, learner choice and honest uncertainty.

M1 does not claim CEFR A1, fluency or an IELTS band. Its proof is meaningful beginner communication plus initial independent, retention and transfer evidence.
