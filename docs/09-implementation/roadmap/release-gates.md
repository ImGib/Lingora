# Release Gates

Every release records pass/fail/not-applicable and evidence for:

1. **Technical:** build, contracts, migrations, idempotency, rollback/degraded paths.
2. **Content:** complete, versioned, reviewed, healthy; quarantine works.
3. **Pedagogy/measurement:** claim alignment, valid opportunities, support provenance, sufficient reliability for each decision.
4. **Data:** lineage, reproducibility, invalidation/reprojection and observability.
5. **Security/privacy:** authentication, learner isolation, least privilege, retention/deletion and artifact access.
6. **Accessibility:** keyboard, focus, labels, contrast, captions/transcripts where appropriate, reduced motion and device constraints.
7. **Operations:** failure recovery, cost/budget limits and incident ownership.
8. **Learner validation:** representative users can complete the intended journey and the measured outcome supports the claim.

High-impact decisions require explicit evidence-burden review. Feature flags cannot silently change evidence meaning.
